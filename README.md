# Geometry Library (Project Linalg)
## Цель работы
Проектирование иерархии классов с использованием динамического полиморфизма и абстрактных интерфейсов.

Задача направлена на освоение принципов инкапсуляции геометрии объектов, механизмов переопределения (override) методов и реализации паттерна Prototype через виртуальный метод clone().

Особое внимание уделено корректному управлению жизненным циклом объектов в полиморфных средах через использование виртуальных деструкторов.

## 🛠 Реализованные классы

### 1. Vector (Вектор)
Класс для работы с двумерными векторами.
* **Операторы**:
    * `+`, `-`, `+=`, `-=` — сложение и разность векторов.
    * `*` — скалярное произведение.
    * `^` — векторное (косое) произведение.
    * `*`, `*=` — умножение на число (поддерживается `vector * scalar` и `scalar * vector`).
    * Унарный `-` — инверсия направления.
* **Методы**: `get_x()`, `get_y()`.
* **Особенности**: Реализована перегрузка разности двух точек (`Point - Point`), возвращающая вектор.

### 2. Иерархия фигур (IShape)
Все фигуры наследуются от абстрактного базового класса `IShape`.

| Фигура | Описание | Геттеры |
| :--- | :--- | :--- |
| **Point** | Точка ($x, y$) | `get_x()`, `get_y()` |
| **Segment** | Отрезок между двумя точками | `get_a()`, `get_b()` |
| **Line** | Прямая $ax + by + c = 0$ | `get_a()`, `get_b()`, `get_c()` |
| **Ray** | Луч (точка начала + вектор) | `get_a()`, `get_vector()` |
| **Circle** | Окружность (центр + радиус) | `get_centre()`, `get_radius()` |

---

## 📐 Общие методы интерфейса IShape

Каждый производный класс реализует следующие методы:
* `void move(const Vector&)` — перемещение фигуры на заданный вектор.
* `bool contains_point(const Point&)` — проверка, лежит ли точка на/внутри фигуры.
* `bool cross_segment(const Segment&)` — проверка пересечения фигуры с отрезком.
* `IShape* clone()` — создание глубокой копии фигуры (динамическая аллокация).
